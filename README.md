# 大观园 · 信号与系统智能研学刷题平台 (DaGuan Signals & Systems Quiz)

> 深度复刻与增强 **大观园研学知识库（cxyonly.fans/math）** 的刷题交互体系，专为 **广东工业大学（广工 837 / 809 · 信号与系统）考研与期末** 深度定制的现代化在线刷题与知识攻坚平台。

---

## ✨ 核心特色与功能模块

1. **章节专项刷题（Chapter Practice）**
   - **严格按照考研统考 7 大核心章节归纳**：
     - 第一章：信号与系统基础（周期性判定、冲激/阶跃特性、五大系统特性、能量/功率）
     - 第二章：系统的时域分析（微分/差分方程、零输入/零状态响应、卷积积分与卷积和）
     - 第三章：频域分析与傅里叶变换（傅里叶级数FS、傅里叶变换FT、对偶性、频响与稳态、无失真传输）
     - 第四章：拉普拉斯变换与复频域分析（单边LT、收敛域ROC、部分分式反变换、电路模型、全通系统）
     - 第五章：Z变换与离散系统（DTFT、Z变换与反变换、ROC形态、因果稳定性、朱利准则、梳状滤波）
     - 第六章：系统状态变量与信号流图（状态方程、输出方程、梅森增益公式Mason's Formula）
     - 第七章：时域抽样与恢复（奈奎斯特抽样定理、频带展宽加倍、混叠失真防范与信号恢复）
   - **状态智能过滤**：全部 / 未做 / 错题 / 已攻克 / 重点标记 瞬时切换。
   - **LaTeX 严谨数学公式原生渲染**：内置 KaTeX 引擎，所有分式、积分、极限、对齐方程全部高质量排版呈现。
   - **原位解析卡片**：【核心考点】、【步骤推导】、【避坑警示】名师级权威详解。
   - **随题专属笔记便签**：每题均可随时撰写个人复盘心得，本地自动同步持久化。
   - **右侧悬浮/抽屉答题卡**：全景状态着色（未做、正确、错误、当前），点击题号毫秒级瞬时跳转。

2. **全真模拟机考 · 智能组卷（Mock Exam）**
   - **仿真考场模式**：可自定义学科、抽题数量（5 / 10 / 20 / 30 / 50 题）与限时倒计时（15 / 30 / 60 / 120 / 180 分钟）。
   - **沉浸式考试界面**：考中不漏答案解析，倒计时红黄色预警，支持试题标疑待查。
   - **考后综合成绩单**：自动评分算分、考情分析、答题耗时统计，伴随胜利礼花，并提供逐题对照复盘。

3. **错题攻坚本（Wrong Book）**
   - **错题自动收录**：答错的题目自动入库，记录错误频次。
   - **一键导出为 Anki 记忆卡片（TSV）**：支持将错题一键导出为 Anki 牌组，随时在手机端利用碎片时间背诵复习！
   - **攻坚掌握标记**：复测攻克后可标记“已攻破掌握”完成归档。

4. **学情大数据看板（Stats & Mastery）**
   - 掌握度雷达与进度条：直观展示各章节题库覆盖率、综合正确率与掌握数。
   - 机考历史战绩档案追踪。

5. **全键盘盲操支持（Keyboard Navigation）**
   - `1 / 2 / 3 / 4` 或 `A / B / C / D`：极速单选/多选/判断作答
   - `J` 或 `←`：切换上一题
   - `K` 或 `→`：切换下一题
   - `Space`（空格）：展开 / 收起原位解析
   - `S`：重点收藏标记
   - `M`：标记考点已彻底攻破掌握
   - `C`：原位复制 LaTeX 题面与解析至剪贴板
   - `Enter`（回车）：多选题确认作答

## 🚀 启动与使用

双击根目录下的 `start.bat` 或在终端运行：
```bash
npm run dev
```
本地浏览器访问 `http://localhost:5173` 即可开启刷题！
